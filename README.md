## How to Run

Compile and execute any program using a C++ compiler (e.g., g++):

```bash
g++ filename.cpp -o output_name
./output_name
```

Example:

```bash
g++ 2_error_detection_and_correction.cpp -o 2_error_detection_and_correction
./2_error_detection_and_correction
```
